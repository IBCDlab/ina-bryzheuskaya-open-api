# ina-bryzheuskaya-open-api
an art API from the Art Institute of Chicago
[My Open API Project](https://github.com/IBCDlab/ina-open-api)

## About the project
This project is a small responsive web application built with HTML, CSS, and JavaScript.
It uses the Art Institute of Chicago API to display data from two categories:
- Artworks
- Artists
The page includes two buttons that let the user switch between artworks and artists. After clicking a button, the application sends a `fetch` request to the API, receives data, and displays the first 10 results as cards on the page.

## How to run
Download or clone the project files.
Open the project folder in VS Code or another code editor.
The folder structure is:
index.html
index.css
js/index.js
Open index.html in your browser or  use Live Server in VS Code for easier testing.
